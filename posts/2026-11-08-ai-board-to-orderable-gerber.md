# 21 段轮廓拼不出一个外形：把 AI 生成的板子做到可下单

## 拆开打样包，先别跑 DRC

硅流生成的这块无人机控制板，打样包解开是 7 个文件。我拿到它的第一件事不是跑 DRC——它加载不进 KiCad，打开就报版本语法错误。所以我先写了个只做**结构完整性**审查的小脚本，0.04 秒解析完，出了三个硬伤：

- 板框层 `boardoutline.gko` 有 **21 条轮廓，其中 21 条都闭合**。数量对，外形错：CAM 要的是唯一闭合外形，21 个圈就是 21 块板，判「轮廓不唯一」直接退回。
- 顶层铜 bbox 是 `(2.0,2.0)~(158.0,158.0)`，板框 bbox 是 `(24.5,24.5)~(135.5,135.5)`。四边各多出 22.5mm，铜铺到板外，等于整板短路。
- 钻孔 bbox `(0.3,0.3)~(15.7,15.7)`，和板框不同源。前两条修了，工厂按钻孔原点定位也会整板偏位。

软缺口更有信息量：**钻孔 4 个，焊盘 167 个**；底层铜（`.gbl`）压根没有，只能做单面板。

## 可加载之后，才看得见真实问题

这一版我叫它 v1。先修 5 处版本语法混写——板级 `fp_text`、`model` 的 `xyz`、`justify center`、`visible_elements`、`design_rules`——文件能加载了，再跑真实 DRC：**428 违规 / 13 未连接**。

然后才是诊断。四条根因，每条都能对上前面看到的数字：

1. 板框是中心圆加四个沿对角线的圆，各画各的，21 段拼不成一条闭合曲线——这就是「21 条轮廓都闭合」的来历。
2. 封装全是 `module Custom` 的假焊盘，有 pad 没有孔——167 个焊盘只出 4 个钻孔。
3. 64 个网络里 51 个是孤儿，只剩 13 个真网络（v3 的电气骨架就是这 13 个）。
4. `PB0` 把 `R7` 两个脚接到了同一个网上，按键读不出电平。

## 两次重建

v2 换官方真封装、板框改成闭合矩形、补上 3.3V 来源的 LDO、BOOT0 下拉、蜂鸣器基极电阻，到 0/0——但它是 70×70 方板。

v3 才是 X 形四臂：中心 60×60 放全部飞控电路，四条 18mm 宽对角臂只承担电机座和电调焊盘，外轮廓用射线求并集，得到**一条**闭合曲线。每臂 4×M2 电机座（12×12 阵列），臂端 r11.5 圆；每臂一个 1×3 电调焊盘（SIG/5V/GND）；`PA0–PA3` = `TIM2_CH1–CH4` → `MOTOR1–4`。布线上 Freerouting 2.4.1 把 127 条未布通的跑到 0。

结果：136.2×136.2mm，2 层，24 个网络 0 个孤儿，461 段走线 / 39 个过孔 / 总长 1849mm，最小线宽 0.15mm，DRC 0 违规 0 未连接。`xfab/` 出 10 个文件：7 个 Gerber 层（F/B 铜、阻焊、丝印、板框）+ `.gbrjob` + Excellon 钻孔 + 贴片坐标 `pos.csv`。

## 那个 0 靠什么成立

两个前提必须说清楚，否则这个 0 传出去就是负债。

**428 会浮动。** 短路是成堆重叠的铜，「谁和谁撞」的配对列举换一次 DRC 就变，复测得 419 条，未连接数恒定 13。所以对外说「四百多条」，要报精确数就附报告文件。

**0/0 不是白捡的。** 0.15mm 最小线宽写在 `xframe_routed.kicad_dru` 里，必须与 PCB 同名同目录：

```lisp
(version 1)
(rule "min track 0.15mm (fab capability, JLCPCB/HQPCB standard)"
    (constraint track_width (min 0.15mm)))
```

删掉它，用 KiCad 默认 0.2mm 跑，会报 25 条 `track_width`——那是工艺设定差异，不是走线有问题。更早一次 0 是我在 pcbnew 内存里改了 `m_TrackMinWidth`，规则没落盘，换台机器复跑就对不上。不可复现的通过等于没通过。

还有一层：`x_drc7.json` 里带了 5 项 `ignored_checks`（`missing_courtyard`、`track_not_centered_on_via` 等），而且没有原理图工程，`schematic_parity` 是空的。所以这个 0 的准确说法是「几何与工艺层面 0 违规」。

## 别把两种产品混成一句

这里最容易写错的一句话是「X 形是错的」。四轴本来就有两种形态：**飞控模块（stack）**是方板，30.5×30.5 或 36×36 孔距，四颗 M3 穿减震柱装在碳纤维机架的塔柱上，板子只管控制、不承力；**一体化机架板**把机架和飞控做成同一块板，臂端直接装电机。v3 做的是后者，板上 16 个孔全是 M2 电机座，一个塔柱孔都没有——因为它自己就是机架，代价是摔机断臂就断板。

v1 的问题不是选了 X 形，是只画了外形、没做布尔并集。

## 剩下的三笔账

没有 `.kicad_sch`，ERC 从没跑过；MPU6050 的 QFN-24 是照数据手册记忆接的线，几何 DRC 查不出电气错，打样前得逐脚复核；没有实物。DRC 0 只证明几何和工艺可行，不证明上电能跑。

可搬走的动作只有一个：拿到 AI 生成的打样包，第一件事不是跑 DRC，是把板框层和铜层的 bbox 对一遍——轮廓是否唯一、铜是否越界、钻孔原点和板框是否同源。这三条在秒级的结构审查里就能判死，比读任何日志都快。生成器最容易错的地方是轮廓不闭合和布尔并集，不是元件摆放。
